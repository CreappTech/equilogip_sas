# skills/

Skills de agentes: convenciones, playbooks y guías reutilizables.

Cada carpeta contiene una skill específica con su propio `SKILL.md` describiendo:
- Cuándo se activa
- Qué produce
- Cómo se usa

No crear una skill nueva si una existente ya cubre el caso (ver AGENTS.md §29).

Las skills existentes heredadas del proyecto viven en `.agents/skills/`. Esta carpeta `skills/` queda como ubicación estándar para skills nuevos del monorepo.
